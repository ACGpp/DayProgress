DayProgress · macOS 13+ · Apple Silicon / Intel

拖进去，再允许首次打开。

不需要安装其他软件，也不需要终端命令。更新前，请先从菜单栏退出旧版 DayProgress。

  1. 拖到「应用程序」
    将同一窗口里的 DayProgress.app 拖到 Applications 文件夹。如果是更新，选择「替换」，原有设置会保留。ZIP 用户也可以在 Finder 中打开「应用程序」后拖入。
  2. 从「应用程序」打开一次
    不要一直从下载目录或磁盘映像内运行。如果提示无法验证开发者或 Apple 无法检查是否包含恶意软件，先关闭提示。
  3. 在系统设置里允许
    打开「系统设置 → 隐私与安全性」，向下找到 DayProgress 的拦截提示，点「仍要打开」，按系统提示确认。如果没有按钮，先回到「应用程序」尝试打开，再回此页面。受组织管理的 Mac 可能需要管理员处理。
  4. 看屏幕右上角
    启动后找菜单栏的沙漏和百分比。它没有 Dock 图标；首次运行会出现欢迎窗口。安装完成后可推出 DayProgress 磁盘映像。
为什么需要多一步？
这是免费开源应用，目前没有 Apple Developer ID 签名和公证。DMG 只是让安装更直观，不会绕过 macOS 安全检查。请仅从 官方 GitHub Release 下载。不要关闭系统全局安全检查。macOS 15+ 不建议依赖右键「打开」。

如果提示「已损坏」且没有「仍要打开」：先删除这次下载的副本，从官方页面重新下载；仍失败时查看 完整安装帮助。只有确认来源和完整性后才考虑其中的单应用终端替代方法。

退出：菜单栏图标 → 面板底部「退出」。登录启动：齿轮设置 →「登录时启动」，必要时到「通用 → 登录项」允许。

Install DayProgress

  1. Quit the old version, then drag DayProgress.app into Applications. Choose Replace when updating; preferences are preserved.
  2. Open it from Applications once. If macOS blocks it, dismiss the warning.
  3. System Settings → Privacy & Security → Open Anyway. Confirm the prompt. If the button is missing, attempt to open the app first. Managed Macs may require an administrator.
  4. Look for the hourglass in the top-right menu bar. There is no Dock icon. Eject the disk image after installation.

This open-source app does not have Apple Developer ID signing or notarization. The disk image does not bypass Gatekeeper. Download only from the official release above. Do not disable system-wide security. For a damaged-app warning, download again before consulting the full installation help.
