DayProgress 安装 / Installation

1. 更新前先退出旧版。将 DayProgress.app 拖进 Applications（应用程序）。
2. 从「应用程序」打开一次；若被拦截，关闭提示。
3. 系统设置 → 隐私与安全性 →「仍要打开」。
4. 启动后看右上角菜单栏的沙漏；没有 Dock 图标。

详细说明：双击「先看这里-安装指南.html」。
本应用没有 Apple Developer ID 签名和公证，磁盘映像不会绕过安全检查。

Quit the old version. Drag the app into Applications, then open it there.
If blocked: System Settings → Privacy & Security → Open Anyway.
Look for the hourglass in the menu bar (no Dock icon).
Open the HTML guide for bilingual instructions.
